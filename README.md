# Luyện tiếng Việt

Trang bài tập tương tác dành cho học viên nước ngoài luyện các cấu trúc tiếng Việt trong chủ đề giải trí. Nội dung gồm 5 dạng bài với 20 câu hỏi, phản hồi đáp án, giải thích ngữ pháp và theo dõi tiến độ.

## Yêu cầu

- Node.js 20 LTS trở lên
- npm 10 trở lên

## Chạy dự án

```bash
npm install
npm run dev
```

Sau đó mở địa chỉ Vite hiển thị trong terminal, thông thường là `http://localhost:5173`.

## Mã nguồn chính

- `src/App.jsx`: nội dung bài tập và toàn bộ logic tương tác
- `src/styles.css`: giao diện responsive cho desktop, laptop và điện thoại
- `src/assets/logo.png`: logo dùng trong phần nhận diện thương hiệu
